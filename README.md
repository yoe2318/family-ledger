# 記帳（家庭記帳 App）

每個人自己的記帳本。帳**只存在自己的手機**（瀏覽器的儲存空間），不會上傳到任何地方；家人每個人裝一次，各自是一本全新的空帳本，互相看不到。

## 家人怎麼安裝
- **iPhone／iPad**：用 Safari 打開網址 → 點下面的「分享」→「加入主畫面」→「新增」。一定要從主畫面的 App 打開（只開在 Safari 裡，太久沒用可能被系統清掉）。
- **Android（Samsung）**：用 Chrome 或 Samsung 瀏覽器打開網址 → 右上角選單 →「安裝應用程式」或「加到主畫面」。
- 裝好後從桌面打開，全螢幕、沒網路也能記。

## 怎麼用
- **點一下** 下面中間的 ＋：完整的記一筆（支出／收入、分類、細項、付款方式、日期、備註）。
- **按住** ＋ 往上劃：先經過內圈選付款方式，停在外圈的分類放手，再打金額就記好了。
- 金額可以打算式，例如 `120+35`。
- 首頁的「常用捷徑」：一點就記（沒寫金額的會跳出鍵盤）。記一筆時勾「存成常用捷徑」就會出現在首頁。
- 數字鍵盤上面的小把手：點一下收起，按住上下拖調大小；點備註打字時鍵盤會自動收起。
- 外觀：9 套主題風格（手帳、牛皮紙、收據、夜空、海洋、森林、極簡、蝴蝶結、口袋藍）一鍵套用，之後主色、背景、紋路、字體、圓角都能單獨改；自訂背景圖片存在這台手機的 IndexedDB，不進備份。
- 更多：借入借出、存錢目標、每月預算、固定收支（每月自動記）、分類／細項、付款方式、扇形選單、外觀（主色、背景顏色和款式、深淺色、鍵盤大小）、每月起算日、備份與還原。

## 帳戶（郵局、錢包、信用卡）
- 「更多 → 帳戶」：按「快速設定」建立郵局、錢包、信用卡，填現在有多少錢；設定「付款方式從哪裡扣」和「收入預設存入」，之後記帳不用再選。
- 帳戶之間搬錢（提款、繳卡費）用「移動」，不算支出：首頁帳戶列的「移動」、記一筆的「移動」分頁、或存成捷徑（例如提款 1000）。
- 信用卡設結帳日、繳費日：結帳後首頁提醒這期卡費，繳完按「已繳」就從郵局扣。
- 帳戶列要設過起始餘額才會出現在首頁。

## 朋友分帳（LINE 記帳群組連動）
- 只有拿到連動碼的人才有這個功能；沒連動的人（家人）完全看不到。
- 在 LINE 私訊記帳機器人「連動碼」→ 它回 8 碼（例如 K7P2-9QXA）→ App「更多」最下面「輸入朋友帳連動碼」→ App 出現「更多 → 朋友分帳」，只看得到自己有參加的群組。
- LINE 群組裡的指令：`午餐 120`（我欠對方，兩人群組）、`午餐 120 小明`（我欠小明）、`晚餐 900 平分`（我付、大家平分）、`晚餐 900 平分 小明`（小明付）、`還 500 小明`、`查詢`、`刪除`（刪自己最後一筆）、`群組名 xxx`、`說明`；私訊：`連動碼`、`換連動碼`。
- 開新的分帳本：開一個 LINE 群組，把記帳機器人邀進去。
- 備註可以按「＋ 明細」一列一列填「店家｜吃了什麼｜金額」，金額自動加總。
- 店家與菜單：明細上面有常去的 5 家，點一下就填店名；填了店家，下面列出在這家點過的東西和上次的價錢（點一下就填好）、「跟上次一樣」一次填整張單，選了店家也會自動帶這家常用的分類。「更多 → 店家與菜單」可以自己加菜單、改價錢、拿掉不要的品項、改名或合併打錯字的店家、放一張菜單照片（照片只存在這台手機，不進備份）。
- 快速記：記一筆上面的「朋友帳」分頁（記住上次的人和方式、點常用項目）；扇形選單內圈的「某人付」（劃過再停在分類＝我欠那個人）。首頁有一行整體欠款。這些只有連動過的人看得到。
- 自己分到的那份會自動變成支出（id 是 `fr-…`，備註「朋友帳・項目」），可以在朋友分帳頁關掉。

## 備份（很重要）
換手機、刪掉 App、清除瀏覽器資料時帳會不見。偶爾到「更多 → 備份與還原 → 匯出備份檔」，把檔案存到雲端硬碟或傳給自己。超過 30 天沒備份，首頁會提醒。換手機時在新手機「從備份檔還原」。
